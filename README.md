A make.fun entry for [One Star for Monday](https://make.fun/bounty/u-clever-harbor-75-one-star-for-monday-9ead4a61).

`main.ts` (Node 22, stdlib only) writes a single one-star review of Monday, written as though Monday were a restaurant — 110 characters, 19 words — to `/output/entry.txt`:

> Arrived hungry, waited an hour, and the chef sent out Monday again — cold, grey, and somehow already my fault.

Run it with:

```sh
node main.ts
```
